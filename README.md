# ⚡ ResuCraft AI — NextGen ATS Resume Optimizer

**A free, privacy-first resume optimization engine that scores your resume against any Job Description in real time.**

🌐 **[Live Demo →](https://resucraft.ai)**

---

## What it does

ResuCraft AI reverse-engineers how corporate ATS systems (Workday, Taleo, SAP SuccessFactors, Greenhouse, Lever) evaluate candidates — and helps you beat them:

- **📊 Real-Time ATS Score** — Section-weighted keyword matching, knockout competency detection, quantification analysis, and action verb scoring.
- **🔍 Keyword Gap Radar** — Instantly identifies which must-have skills from the Job Description are missing from your resume.
- **⚡ 1-Click Auto-Tailor** — Automatically injects missing canonical skills into your Skills Matrix and rewrites experience bullets using the **Google XYZ Formula** (*"Accomplished [X] as measured by [Y] by doing [Z]"*).
- **✏️ Full Resume Editor** — Edit every section: Personal Details, Summary, Experience, Skills, Projects, Education, and Certifications.
- **🖨️ ATS-Compliant PDF Export** — 5 professional resume templates with live keyword highlighting and A4 print engine.
- **🔒 100% Private** — Everything runs in your browser. No data is ever sent to any server.

## Quick Start

```bash
# Clone the repo
git clone https://github.com/your-username/resucraft-ai.git
cd resucraft-ai

# Run locally (no npm install needed)
python3 -m http.server 3000

# Open in browser
open http://localhost:3000
```

## Tech Stack

- **Zero dependencies** — Pure HTML5, Vanilla ES6+, and CSS3
- **No build tools** — No Webpack, Vite, React, or npm required
- **No backend** — Fully static, deployable to any CDN
