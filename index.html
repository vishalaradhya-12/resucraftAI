Data Security & Privacy Architecture

How ResuCraft protects your resume, job descriptions, and personal information.

1. 100% Client-Side Parsing, ATS Scoring & PDF Export Uploading PDF/Word files (pdf.js / mammoth.js), keyword matching, bullet tailoring, and PDF generation all execute strictly inside your browser. Zero bytes are sent to any server during normal use.
2. Zero Database & Zero File Storage ResuCraft has no backend database, no user accounts, and no server-side file storage. Drafts are stored only in your own browser's localStorage so you don't lose work on refresh.
3. Optional AI Deep Read (Stateless HTTPS) Only when you explicitly click Deep AI Read, your resume text is transmitted over encrypted HTTPS via a stateless serverless proxy (or directly from your browser if using your own key) to Google's Gemini API and immediately discarded.
